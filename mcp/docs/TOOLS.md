# wowsims-tbc MCP reference

Every tool is a function of its arguments. The server keeps nothing between calls: simulations
are addressed by a content hash of the request, so the same arguments always name the same run,
and any instance can answer for any ID.

## Tools

### `specs_list` — List simulable specs

Lists the class specs this simulator can run, with the gear sets, rotations and builds checked in for each.

Start here when you do not already know what to pass as `spec` elsewhere, or when you want a
named preset to sim rather than assembling gear yourself. Names listed under `presets` are the
names other tools and the wowsims:// resources expect.

Examples:
- list everything: {}

Read-only.
